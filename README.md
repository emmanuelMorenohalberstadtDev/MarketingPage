# MarketingPage

Página de presentación de mis servicios de desarrollo web para negocios y emprendimientos: páginas web, tiendas online, sistemas de turnos y reservas, y sistemas a medida. Cada servicio incluye una demo navegable para ver cómo quedaría.

**Ver la página:** https://emmanuelmorenohalberstadtdev.github.io/MarketingPage/

## Demos

- [Página web](https://emmanuelmorenohalberstadtdev.github.io/MarketingPage/demos/pagina-web.html): ejemplo de una cafetería
- [Tienda online](https://emmanuelmorenohalberstadtdev.github.io/MarketingPage/demos/tienda.html): ejemplo de una tienda de plantas
- [Turnos y reservas](https://emmanuelmorenohalberstadtdev.github.io/MarketingPage/demos/reservas.html): ejemplo de una barbería
- [Sistema a medida](https://emmanuelmorenohalberstadtdev.github.io/MarketingPage/demos/sistema.html): ejemplo de un panel de ventas y stock

## Cómo editarla

Los datos de contacto, servicios y precios están en `config.js`. Lo que se cambie ahí se actualiza solo en la página.

Hecha con HTML, CSS y JavaScript, sin dependencias.
